# 简历岗位简报

## 目标

从 JD 中提取岗位使命、核心职责、必须条件、加分条件和 ATS 关键词，形成可以指导简历排序的招聘方简报。这里只分析岗位，不替候选人主张任何能力。

## 执行规则

- 先识别岗位真正解决的问题和成功标准，再拆分要求。
- 分为 `must` 与 `preferred`。职责、明确年限、硬性工具、学历或资格要求通常属于 `must`；措辞为优先、加分、熟悉更佳的内容属于 `preferred`。
- JD 明确写出的学历／专业、工作年限、资格、证书和硬性工具要求必须各自进入岗位重点；候选人证据不足只能降低覆盖强度，不能从简报中省略该要求。
- 合并同义要求，不把一句 JD 机械拆成多个重复条目。
- ATS 关键词保留 JD 的实际说法，包括常用缩写；不要自行补充 JD 未出现的工具、证书或职级。
- 招聘宣传、公司介绍和泛化软技能只在能影响简历排序时保留。
- 每条岗位要求都保持为“岗位需要什么”，不得改写成“候选人具备什么”。
- 简历策略优先覆盖证据最强的 `must` 要求；证据弱或缺失的要求可以记录缺口，但不能靠措辞弥补。

## 输出倾向

- 岗位重点通常控制在 3 至 6 项，按招聘决策影响排序。
- 关键词只用于后续核对和自然嵌入，不堆砌。
- 简要说明目标岗位真正看重的结果或工作方式，供摘要和经历排序使用。
